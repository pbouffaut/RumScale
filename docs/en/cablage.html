RumScale · assembly sheet

Wiring the ideaspark board

Current setup: four half-bridge load cells combined into one full bridge, one HX711, and an ESP32-WROOM-32 board with a 1.9" ST7789 display. The diagrams below show the alternative setup with two HX711 modules and two four-wire load cells.

Current setup — one HX711 A

DT / DOUT → GPIO 25 · SCK → GPIO 26 · VCC → 3V3 · GND → GND. The four half-bridge load cells form one full bridge connected to the module’s E+, E−, A+ and A− terminals. The wire colours in the four-wire diagram below do not describe their individual connections.

NUM_CHANNELS is set to 1 in src/config.h. A second HX711 is not needed. The button is optional: two quick taps on the base wake the sleeping display, and the web app provides access to settings.

Alternative setup shown below: two full-bridge load cells, each connected to its own HX711. Set NUM_CHANNELS to 2, rebuild and recalibrate; A stays on 25/26, while B uses 16/17.

Three mistakes that can cost you a day

1. Do not power the HX711 modules with 5 V. Their DOUT output would follow the 5 V supply, exceeding the ESP32 GPIO ratings. Connect all power inputs to the 3V3 pin.

2. A shared ground is essential. Without a shared GND between the ESP32 and both HX711 modules, readings can stay at zero or drift unpredictably.

3. Leave GPIO 2, 4, 15, 18, 23 and 32 alone. The board’s display already uses them.

03Two-bar alternative — mechanical base

This part determines measurement quality. A bending-beam load cell only measures correctly if it can bend : one end attaches to the bottom plate, the other to the platform, with clearance in between.

  1. The platform must touch only the load cells. No other support, trapped cable or rubbing screw: any unwanted contact diverts weight away from the measurement.
  2. A spacer at each end of each load cell allows the bar to flex freely.
  3. Tighten securely. A screw that gradually loosens causes slow drift — which the firmware may interpret as evaporation.
  4. Position the cells symmetrically on either side of the centre, with the barrel always in the same place. This allows a single calibration factor to work for both cells.
  5. Mount the electronics on the bottom plate, leave slack in the cables, and keep the board as far from the load cells as possible: heat causes measurement drift.

04Check before closing the enclosure

  1. Connect USB and open the serial console. The current setup reports 1 canal/canaux HX711 initialisé(s) (one initialized HX711 channel); the two-module alternative, built with NUM_CHANNELS = 2, reports two.
  2. In the web app, check that the raw reading responds. If a button is installed, the display’s Diagnostic page (diagnostics) also lets you check active channels. If a module gives no response, check its DT, SCK and power connections.
  3. Press the platform with your finger: the raw value should change. Calibration with a known weight accounts for the signal direction.
  4. Press one corner and then the other: both should affect the reading. If not, check that every load cell properly supports the platform.
  5. Join the RumBarrel-setup network, set up Wi-Fi, then complete the four initialization steps in the app.
